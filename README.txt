EXPLORE CIPELAH — TRAVEL DISCOVERY

Desain: Travel Discovery dengan warna biru langit dan putih.

Cara menjalankan di VS Code:
1. Ekstrak ZIP.
2. Buka VS Code > File > Open Folder.
3. Pilih folder Explore_Cipelah_Travel_Discovery.
4. Buka index.html.
5. Klik kanan index.html > Open with Live Server (jika ekstensi Live Server terpasang), atau buka index.html langsung di browser.

Fitur:
- Landing page Travel Discovery.
- Galeri foto dengan filter kategori dan lightbox.
- Kartu paket aktivitas (contoh/inspirasi, bukan paket resmi).
- Weather check: tanggal, tips berdasarkan kondisi pilihan, tautan pencarian prakiraan cuaca terbaru.
- Ulasan contoh yang diberi label sebagai demonstrasi.
- Tombol Google Maps untuk mencari Curug Cipelah, Cianjur.
- Responsive untuk layar HP dan desktop.

Foto Curug Cipelah yang kamu kirim disimpan di folder assets.
Harga tiket, fasilitas, jam buka, cuaca live, dan ulasan asli belum diverifikasi; website tidak mengarang data tersebut.
