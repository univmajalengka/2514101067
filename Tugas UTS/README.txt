PROGRAM MENGHITUNG DISKON

Isi folder:
- index.php : program utama untuk menghitung diskon dan menampilkan hasil.

CARA MENJALANKAN DENGAN XAMPP:
1. Ekstrak folder Program_Diskon dari file ZIP.
2. Salin folder Program_Diskon ke dalam C:\xampp\htdocs\
3. Buka XAMPP Control Panel.
4. Klik Start pada Apache. MySQL tidak perlu dijalankan.
5. Buka browser dan kunjungi:
   http://localhost/Program_Diskon/

CONTOH:
Total belanja = Rp120.000
Diskon 10% = Rp12.000
Total bayar = Rp108.000

Untuk mengubah contoh total belanja, edit nilai:
$totalBelanja = 120000;
di dalam file index.php.
